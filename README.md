## 🛠️ Tecnologias

- HTML semântico para a estrutura.
- CSS para o estilo: variáveis, Flexbox, Grid e `clamp()`.
- JavaScript puro para o tema claro/escuro e os diálogos de projetos e certificados.
- Git e GitHub para versionamento e GitHub Pages para a publicação.

## 📄 Sobre o Projeto

Um portfólio de uma página que apresenta quem eu sou, os projetos que construí e os cursos que concluí. O foco está em:

- **Responsividade:** o layout se adapta a qualquer tela, do celular ao monitor ultrawide, com conteúdo centralizado e tipografia fluida.
- **Tema claro e escuro:** alternância entre os dois temas, inclusive nos diálogos.
- **Projetos e certificações:** cards que abrem os detalhes, com link para o código e para o site de cada projeto.
- **Acessibilidade e desempenho:** HTML semântico, imagens com texto alternativo e carregamento preguiçoso.

## 🚀 Como rodar

Não há dependências. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/ruhancmendes/Portfolio.git
```

## 🛠️ Technologies

- Semantic HTML for structure.
- CSS for styling: variables, Flexbox, Grid and `clamp()`.
- Vanilla JavaScript for the light/dark theme and the project and certificate dialogs.
- Git and GitHub for version control, GitHub Pages for hosting.

## 📄 About the Project

A single-page portfolio that presents who I am, the projects I built and the courses I completed. The focus is on:

- **Responsiveness:** the layout adapts to any screen, from phones to ultrawide monitors, with centered content and fluid typography.
- **Light and dark themes:** switch between both, dialogs included.
- **Projects and certifications:** cards that open their details, with links to each project's code and live site.
- **Accessibility and performance:** semantic HTML, images with alt text and lazy loading.

## 🚀 Running locally

There are no dependencies. Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/ruhancmendes/Portfolio.git
```
